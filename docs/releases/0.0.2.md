# Radio Rubben Studio 0.0.2

- Privat redaksjonell innboks på `/robot.php` for innloggede medarbeidere.
- Viser Bømlo kommunes RSS-saker som kildekort med original lenke; leser privat RR Robot-eksport når den finnes, ellers den offentlige RSS-strømmen ved sidevisning.
- Støtte for kampforslag fra RR Robot når en privat eksportfil er overført.
- Ingen automatisk artikkelpublisering. Eksisterende Entra-innlogging og Studio-modus beholdes.

Publisering forutsetter vellykket kontroll og `apply` i Studio sin avgrensede Uniweb-deploy. En grønn GitHub-kjøring alene betyr ikke at nettsiden er oppdatert.
