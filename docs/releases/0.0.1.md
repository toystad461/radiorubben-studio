# Radio Rubben Studio v0.0.1

Første nummererte webrelease av det eksisterende PHP-kontrollsenteret.
Mål: `https://studio.radiorubben.no`. Repository: `toystad461/radiorubben-studio`.

## Innhold

Eksisterende norsk Studio-grensesnitt, visuell Radio Rubben-profil, venteside og
Microsoft Entra-basert innloggingskode videreføres. Det innføres versjonsfil,
byggmanifest med eksakt commit, versjonert Uniweb-pakke og SHA-256-kontrollsum.
Node.js/npm er ikke nødvendig for denne webutgaven.

## Publisering

Releaseutkastet opprettes etter tester på PHP 8.2 og 8.4. Det publiseres ikke som
ferdig GitHub-release før en eksplisitt aktivert Studio-deploy har kopiert pakken
og verifisert HTTPS-svar og release.json på riktig domene. En prøvekjøring endrer
ikke nettstedets filer. GitHub Actions oppgir faktisk status i kjøringssammendraget.

Bare Studio-mappene berøres. Lokal serverkonfigurasjon og innloggingsmodus beholdes.
En eksisterende venteside blir ikke automatisk erstattet av et offentlig dashboard.
Dersom ventesiden er aktiv, er en vellykket deploy en oppdatering av den lukkede
webutgaven – ikke en bekreftelse på at medarbeiderinnlogging er ferdig aktivert.

## Avgrensninger

Denne versjonen er ikke det komplette AI Studio-konseptet. RØDECaster/MIDI,
AI Producer, direkte Radio.co-kontroll og aktive OneDrive/WordPress-integrasjoner
er ikke levert i denne releasen. Reell Entra-innlogging må testes med autorisert
og uautorisert bruker før intern lansering. Backup er en kodebackup av Studio,
ikke backup av OneDrive, mediefiler eller databaser.

Se `docs/STUDIO-DEPLOY.md` for oppsett, kontroll, publisering og tilbakeføring.
