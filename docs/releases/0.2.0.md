# Radio Rubben Studio v0.2.0 – L02

Offisiell L02-release for aktiv VPS 5.249.252.78. Kontrollrom, sendekø,
privat lytting, cue inn/ut, 3+1-rotasjon og jingle uten overlapp er kontrollert.
Synlig miljømerking og avspillingsknapper bruker ordinære driftsnavn.
Eksisterende Microsoft-innlogging, roller og private lytterrettigheter beholdes.

Dette er en selektiv VPS-release. Git-taggen identifiserer kildehistorikken;
vedlagt deploymanifest identifiserer faktisk installerte filer. Hele kildearkivet
skal ikke kopieres over aktiv server. Uniweb og WordPress er ikke oppdatert.
Interne kompatibilitetsbaner, historiske testbevis og automatiske tester beholdes.
Syntetiske redaksjonelle prøvesaker blir ikke ommerket til virkelig innhold.
Full mikrofonmiks/L05, TTS-automatikk og WordPress-integrasjon inngår ikke.

Privat backup opprettes før installasjon. Ingen lydtjeneste startes på nytt.
