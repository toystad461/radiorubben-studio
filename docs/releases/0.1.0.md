# Radio Rubben Studio – Versjon 0 (v0.1.0)

Samlet startpunkt for videre utbygging, etablert 7. oktober 2026.

## Innhold

- Konsolidert Studio på Uniweb med Microsoft-innlogging og eksisterende roller.
- Kontrollsenter med Saker til behandling, kanalvalg radio/nett/begge og Radioliste.
- Nyhetsdesk med RSS, radio-/nettutkast, kilde- og språkkontroll, revisjoner,
  historikk og manuell redaksjonell sluttgodkjenning.
- Pensjonert Robot-side; gamle bokmerker går til den autentiserte Nyhetsdesk.
- Rettet avsnittskontroll og presiserte kildeforbehold i fremtidige nettutkast.
- Entra-forhåndskontroll og dokumentert gjennomgang av alle tidligere åpne PR-er.
- Selektiv GitHub-utrulling med filhasher, privat backup og tilbakeføring.
  Offentlig release.json viser versjon og eksakt publisert Git-commit; feil
  manifestkontroll utløser tilbakeføring før deploystatus avanseres.
